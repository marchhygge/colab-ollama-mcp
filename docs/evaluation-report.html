⚙️ Scope 1: Core MCP Server Hardening (Stream 1 — Remediated)
Target files: colab_ollama_mcp/server.py pyproject.toml
Score: 6.5 → 9.5 / 10
Priority Vulnerability / Bottleneck Root Cause Analysis Implemented Remediation in server.py
P0 SSRF & Arbitrary Scheme Injection in ollama_set_endpoint urllib.request.urlopen() accepts file://, ftp://, and internal LAN/metadata IPs (169.254.169.254, 10.*, 192.168.*). Unvalidated URLs allowed probing local files or internal ports. Added validate_endpoint_url(url: str) -> tuple[bool, str] using urllib.parse.urlparse. Allows only https:// public hostnames or explicit http://localhost[:port] / http://127.0.0.1[:port]. Enforced in set_endpoint_in_configs() and call_ollama_api().
P0 Unguarded Type Casts & Missing MCP "isError": True float(args.get("temperature", 0.2)) and int(os.environ.get("OLLAMA_TIMEOUT")) could crash the stdio process on malformed input; tool errors returned normal text without "isError": True. Guarded DEFAULT_TIMEOUT and temperature parsing, wrapped tool dispatch in try/except Exception returning JSON-RPC -32603, and set "isError": True whenever a tool response starts with ❌.
P1 Double Tunnel Round-Trip on Every ollama_chat resolve_model() called GET /api/tags across the Cloudflare tunnel before every single POST /api/chat request, adding 300–600ms of redundant TLS/tunnel latency. Added 60-second TTL cache _MODEL_CACHE: dict[str, tuple[float, list]] = {} in fetch_available_models(endpoint, use_cache=True), invalidated automatically when set_endpoint_in_configs() updates the endpoint.
P1 Cloudflare HTTP 524 Timeout on Long CoT Generations With "stream": False, Ollama buffered the entire response until generation finished. Reasoning runs >100s on deepseek-r1:14b/32b triggered Cloudflare's 100s idle HTTP 524 timeout. Switched call_ollama_api() to send "stream": True and iterate over NDJSON response lines (with single-JSON fallback), keeping bytes flowing continuously through Cloudflare while returning a complete MCP response.
P1 Partial Config Sync & Env Key Overwrite set_endpoint_in_configs() only updated 2 files and overwrote custom keys in env. Updated set_endpoint_in_configs() to sync antigravity_mcp_config.json, claude_desktop_config.json, and cursor_mcp.json while preserving existing env dictionary keys.
